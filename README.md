# Codex + IIC-OSIC-TOOLS + SKY130A

[English](README.md) | [日本語](README.ja.md)

This GitHub-ready project gives Codex a small, reproducible command-line
interface to IIC-OSIC-TOOLS. OpenADA and MCP are not required. The container
image and SKY130/open_pdks revision are pinned in `docker/environment.lock.json`.

## Quick start

```sh
make start
make doctor
make smoke
make inverter
make xschem
```

The project-managed noVNC desktop uses <http://localhost:6080/> by default.
The existing legacy IIC container is also detected automatically when present.

The wrapper first looks for `codex-sky130-eda`, then the existing
`iic-osic-tools_xvnc_uid_501` container. Override it when needed:

```sh
IIC_CONTAINER=another-container make doctor
```

The deployed copy is expected at `/foss/designs/codex-sky130` inside the
container. Override `IIC_PROJECT` if the host directory is mounted elsewhere.

## Direct EDA access

```sh
bin/eda run xschem --version
bin/eda run ngspice --version
bin/eda run magic --version
bin/eda run netgen -batch
bin/eda run klayout -v
bin/eda shell
```

Every command selects `sky130A` with the IIC-provided `sak-pdk-script.sh`
before invoking the requested tool.

## Files

- `bin/eda`: safe host-to-container command wrapper
- `tests/sky130_nmos_dc.spice`: transistor-level SKY130A smoke simulation
- `build/`: generated logs and data
- `runtime-manifest.json`: detected runtime versions, generated by `make doctor`
- `docker/compose.yaml`: reproducible local IIC-OSIC-TOOLS service
- `docker/environment.lock.json`: pinned image, PDK, and tool versions
- `.github/workflows/verify.yml`: pull-request SKY130 simulation checks

## Version-control policy

Commit design sources, tests, scripts, manifests, and small reviewed reports.
Do not commit the PDK, Docker image, transient build output, raw waveforms, or
credentials. Large reviewed GDS/OASIS deliverables should use Git LFS or a
release artifact rather than ordinary Git history.

## CMOS inverter example

`design/xschem/cmos_inverter.sch` is a transistor-level SKY130A CMOS inverter.
It uses 1.8 V devices with `WN=1.0 um`, `WP=2.0 um`, and `L=0.15 um`.

```sh
make inverter-netlist  # Xschem schematic -> SPICE
make inverter-sim      # DC VTC and metrics
make inverter          # both
make xschem            # open the schematic with the SKY130A symbol paths
```

The default noVNC display is `:1`. Override it with `IIC_DISPLAY` only if the
container was launched with a different X display.

Do not launch this schematic from an Xschem session configured for another
PDK. The project-local `xschemrc` explicitly loads the SKY130A libraries.
